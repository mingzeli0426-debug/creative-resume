# 李明泽 · 交互简历

纯静态网站，适合 GitHub Pages。无需安装依赖或运行构建。

- `index.html`：在线首页，脚本、样式与媒体使用相对路径。
- `assets/`：网页交互、样式、原视频压缩版、封面与简历 PDF。
- `resume.html`：内嵌所有素材的离线单文件，可直接下载后发送。

开场静音播放，可跳过或重播，尊重减少动态效果设置。卡片详情同时提供原生链接方案，在 JavaScript 不可用时仍可阅读。手机端提供独立栏目入口。

手机端使用960像素封面及720p H.264 Baseline兼容视频。浏览器限制自动播放时提供“轻触播放开场”，加载较慢时仍可直接阅读栏目；微信桥就绪时尝试一次恢复播放。移动触屏设备不提前加载四张桌面悬停图，鼠标悬停或键盘聚焦时按需加载。

当前静态封面来自用户视频第一帧。四张人物状态图使用用户原图：01托腮、02托掌、03双手托脸、04眨眼指向；鼠标悬停或键盘聚焦时切换，移开后恢复封面。图片预加载，切换使用320毫秒透明度过渡；减少动态效果时立即切换。图片加载失败时保留封面，仍可点击详情。
